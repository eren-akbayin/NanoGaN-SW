# NanoGaN Measurement Data

## Dependencies

| Package | Version | Purpose |
|---|---|---|
| jupyterlab | 4.5.8 | Notebook environment |
| pandas | — | CSV data loading and analysis |
| numpy | — | Numerical computing |
| matplotlib | — | Plotting phase voltages and currents |

### Setup

```bash
python -m venv nanogan-venv
nanogan-venv\Scripts\activate
pip install jupyterlab numpy pandas matplotlib scipy
jupyter lab
```
